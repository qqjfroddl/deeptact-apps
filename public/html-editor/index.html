1분 빠른 시작

  1. 파일 열기로 수정할 HTML을 선택합니다.
  2. 가운데 화면에서 글자나 이미지를 한 번 클릭합니다.
  3. 글자는 더블클릭해서 입력하고, 크기와 글꼴은 위 도구에서 바꿉니다.
  4. 새 파일 저장을 눌러 `.edited.html` 파일을 받습니다.
  5. 저장한 파일을 새 탭에서 다시 열어 결과를 확인합니다.

글자 수정

  • 한 번 클릭: 제목·문단·목록 항목 선택
  • 더블클릭: 바로 텍스트 편집
  • `텍스트 편집` 버튼: 선택한 글자를 편집
  • Esc: 텍스트 편집 종료

글자 크기와 글꼴

제목·문단·목록 항목을 선택하면 글자 도구가 나타납니다. `−`와 `＋`는 2px씩 바꾸고, `크기 원래대로`는 이 편집기가 적용한 크기를 지웁니다.

글꼴은 원본 유지, Paperlogy, 고딕, 명조, 코드 다섯 가지입니다. Paperlogy는 인터넷이 없는 환경에서 시스템 글꼴로 대신 보일 수 있습니다.

이미지

이미지를 선택하면 크기와 가운데 정렬 도구가 나타납니다. `추가 → 내 이미지`로 넣은 이미지는 HTML 파일 안에 포함되어 별도 이미지 파일이 필요 없습니다.

슬라이드

슬라이드가 두 장 이상 감지되면 왼쪽 목록이 열립니다. 슬라이드를 클릭해 이동하고, 화살표 버튼이나 끌어놓기로 순서를 바꿉니다.

저장 방식

  • 새 파일 저장: 항상 사용할 수 있습니다. 파일명 끝에 `.edited.html`이 붙습니다.
  • 원본에 저장: Chrome·Edge에서 `파일 열기`로 연 경우에만 사용할 수 있습니다.
  • 파일을 끌어다 놓아 열면 브라우저가 원래 위치를 기억하지 못하므로 새 파일로만 저장됩니다.

문제가 생겼을 때

  • 이미지·글꼴이 빠져 보이면 저장 후 원래 폴더에서 다시 확인합니다.
  • 끌어 이동되지 않으면 위·아래 화살표 버튼을 사용합니다.
  • 잘못 바꿨다면 실행취소를 누릅니다.
  • 브라우저를 닫기 전에 `저장되지 않은 변경` 배지가 없는지 확인합니다.
