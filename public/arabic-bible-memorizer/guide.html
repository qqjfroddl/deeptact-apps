📖 아랍어 말씀 암송 — 사용법

앱 열기

매주 외우는 그 구절, 아랍어로.

교회에서 암송하는 말씀을 아랍어로 듣고, 따라 읽고, 가려 가며 외우는 앱입니다. 하루 5분이면 충분해요.

빠른 시작 — ① 여러 번 듣기 → ② 가리며 외우기 → ③ 내 녹음으로 확인. 이게 전부입니다.

홈 화면에 추가 화면 살펴보기 듣기 외우기 내 암송 확인 원어민 음성 구절 관리 자주 묻는 질문

1폰 홈 화면에 추가하기

한 번만 해 두면 폰 첫 화면에 아이콘이 생겨서 앱처럼 눌러 열 수 있어요. 설치가 아니라서 용량도 차지하지 않아요.

아이폰 (Safari)

  1. 사파리로 앱 주소를 엽니다.
  2. 아래 가운데 공유 버튼(네모에 화살표 ⬆︎)을 누릅니다.
  3. 목록에서 「홈 화면에 추가」를 누르고 「추가」를 누릅니다.

안드로이드 (Chrome)

  1. 크롬으로 앱 주소를 엽니다.
  2. 오른쪽 위 점 세 개(⋮) 메뉴를 누릅니다.
  3. 「홈 화면에 추가」를 누릅니다.
카톡·왓츠앱 안에서 열렸다면, 먼저 화면 구석 메뉴에서 「다른 브라우저로 열기」(Safari/Chrome)를 눌러 주세요.

2화면 살펴보기

  • ◀ ▶ — 구절을 앞뒤로 넘깁니다.
  • 가운데 큰 글씨가 구절 이름, 그 아래가 아랍어 본문입니다.
  • 발음 — 한글 발음 표기를 켜고 끕니다.
  • 뜻 — 한국어 본문을 켜고 끕니다.
  • 오른쪽 위 구절 목록 — 전체 구절을 보고 고르는 곳입니다.
앱은 마지막에 보던 구절을 기억해요. 다음에 열면 그 구절에서 바로 시작합니다.

3듣기 — 귀에 익을 때까지

  1. 가운데 ▶ 큰 단추를 누르면 아랍어가 들려요.
  2. 처음에는 느리게를 눌러 두고 들으세요. 익숙해지면 보통 → 원래 속도로 올립니다.
  3. 반복 재생을 켜 두면 끝없이 다시 들려줘요. 들으면서 소리 내어 따라 읽는 게 가장 좋아요.

재생 단추 아래에 지금 어떤 소리인지 표시됩니다.

  • 「원어민 녹음으로 재생돼요」 — 담아 둔 원어민 목소리를 들려줍니다.
  • 「기기 음성(TTS)으로 재생돼요」 — 폰에 내장된 컴퓨터 음성을 들려줍니다.

4외우기 — 조금씩 가리면서

「암송 연습」에서 단계 단추를 차례로 누릅니다.

  1. 전체 보기 — 다 보면서 여러 번 읽습니다.
  2. 조금 가리기 — 몇 단어가 가려져요. 기억해서 채워 읽습니다.
  3. 많이 가리기 — 절반 넘게 가려집니다.
  4. 다 외우기 — 전부 가린 채 암송해 봅니다.

이렇게 가려져요 — قَالَ لَهُ يَسُوعُ

막히면 가려진 상자를 살짝 누르세요. 그 단어만 잠깐 보였다가 다시 가려집니다.

끝까지 외웠다면 다 외웠으면 눌러 주세요 ✓ 를 눌러 완료 표시를 남깁니다. 구절 목록에서 몇 개나 외웠는지 볼 수 있어요.

5내 암송 확인 — 녹음해서 비교

어디가 부족한지 스스로 아는 가장 좋은 방법입니다.

  1. 「내 암송 확인하기」에서 ● 녹음을 누르고 본문을 보지 않고 암송합니다.
  2. 끝나면 ■ 끝내기를 누릅니다. 자동으로 저장돼요.
  3. 비교 듣기를 누르면 ① 원어민 소리 → ② 내 녹음이 연달아 나옵니다. 발음과 빠르기를 견주어 들어 보세요.
새로 녹음하면 이전 녹음 위에 덮어써요. 구절마다 따로 저장됩니다.

6원어민 음성 담기 (강력 추천)

컴퓨터 음성보다 실제 사람 목소리가 훨씬 좋지요. 현지 친구나 선생님을 만났을 때 한 번만 부탁해 보세요.

  1. 화면 아래 「원어민 음성 관리」를 눌러 펼칩니다.
  2. ● 녹음을 누르고 친구에게 구절을 천천히 읽어 달라고 합니다.
  3. ■ 끝내기를 누르면 끝. 그다음부터 재생 단추가 이 목소리를 들려줍니다.

음성 파일을 받았다면 파일 넣기로 담을 수도 있어요. 잘못 담았으면 녹음 지우기로 지웁니다.

7구절 추가와 관리

오른쪽 위 구절 목록을 누르면 전체 구절이 보이고, 맨 위에 「＋ 새 구절 추가」가 있습니다.

  • 추가 — 구절 이름과 아랍어 본문을 넣으면 됩니다. 한국어 본문과 한글 발음은 넣으면 더 좋아요(선택).
  • 고치기 — 각 구절 옆 「고치기」로 내용을 수정합니다. 아랍어에 틀린 곳을 발견하면 여기서 바로 고치세요.
  • 삭제 — 고치기 화면 안에 삭제 단추가 있어요.
  • 기본 구절 10개 복원하기 — 처음 들어 있던 구절을 되살립니다. 직접 추가한 구절은 그대로 남아요.
아랍어 본문은 YouVersion(성경 앱)이나 아랍어 성경 사이트에서 구절을 복사해 붙여 넣는 게 편해요.

8자주 묻는 질문

재생을 눌러도 소리가 안 나요.

기기에 아랍어 음성(TTS)이 없는 경우예요. 휴대폰에서는 대부분 잘 나오고, 컴퓨터에서는 안 될 수 있습니다. 가장 좋은 해결책은 6번처럼 원어민 녹음을 담아 두는 것입니다. 폰 음량과 무음 모드도 한 번 확인해 주세요.

녹음 단추가 안 돼요.

처음 누르면 마이크 권한 창이 뜨는데, 꼭 「허용」을 눌러 주세요. 실수로 거절했다면 브라우저 설정에서 이 사이트의 마이크를 허용으로 바꾸면 됩니다. 또 파일로 저장해서 연 경우에는 녹음이 안 돼요. 꼭 앱 주소로 열어 주세요.

내 기록과 녹음은 어디에 저장되나요?

전부 지금 쓰는 폰(브라우저) 안에만 저장됩니다. 외부로 전송되지 않아요. 대신 브라우저 데이터(방문 기록·사이트 데이터)를 지우면 함께 사라지고, 다른 폰으로는 자동으로 넘어가지 않으니 주의해 주세요.

인터넷이 약한 곳에서도 되나요?

앱을 열 때는 인터넷이 필요해요. 일단 열리면 듣기·연습·녹음은 대부분 폰 안에서 돌아갑니다.

아랍어 본문이 틀린 것 같아요.

기본 구절은 반다이크역을 바탕으로 한 초안이라 틀린 곳이 있을 수 있어요. 구절 목록 → 고치기에서 직접 수정할 수 있습니다. 틀린 곳을 알려 주시면 기본 구절도 바로잡을게요.

구절을 잘못 지웠어요.

구절 목록 맨 아래 「기본 구절 10개 복원하기」를 누르면 처음 들어 있던 구절이 되살아나요. 직접 추가했던 구절은 복원이 안 되니 삭제할 때 한 번 더 확인해 주세요.
